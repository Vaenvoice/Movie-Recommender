# Vaen TV+ 🎬

[![Live Demo](https://img.shields.io/badge/Live-Demo-0071e3?style=for-the-badge&logo=vercel)](https://vaentv.vercel.app/)

A premium, high-fidelity movie discovery and streaming platform inspired by the sleek aesthetics of Apple TV. Built with a modern full-stack architecture, featuring personalized AI recommendations and an immersive user experience.

## 🏗️ Project Architecture

The platform follows a modern full-stack decoupled architecture with a specialized AI layer for real-time recommendations:

```mermaid
graph TD
    User((User)) -->|Interacts| FE[React Frontend]
    FE -->|GET /recommend/personalized| BE[FastAPI Backend]
    
    subgraph "AI Recommendation Engine"
        BE -->|Fetch History/Likes| DB[(PostgreSQL)]
        BE -->|Fetch Candidates| TMDB[TMDB API]
        DB -->|Metadata| Profile[User Profile Generator]
        TMDB -->|Raw Results| Pre[Text Preprocessor]
        Profile -->|Liked Movie Text| Pre
        Pre -->|Cleaned Content Strings| TFIDF[TF-IDF Vectorizer]
        TFIDF -->|Numerical Vectors| SIM[Cosine Similarity]
        SIM -->|Similarity Scores| Rank[Re-ranking Logic]
        Rank -->|Sorted List| BE
    end
    
    BE -->|JSON Response (Top 10)| FE
    FE -->|Visual Feedback| User
```

### 🧠 AI Recommendation Lifecycle
The "Recommended for You" engine uses a content-based filtering approach to provide personalized suggestions:

1.  **Data Ingestion**: The system fetches the user's recently liked movies from the database and candidate movies (trending or similar) from the TMDB API.
2.  **Text Preprocessing**: For each movie, a "content string" is generated by combining the `overview` and `genre` metadata.
3.  **Vectorization**: Using `Scikit-Learn`'s `TfidfVectorizer`, these text strings are transformed into a sparse matrix of TF-IDF features, representing the importance of each word.
4.  **User Profiling**: A unique **User Vector** is created by calculating the **Mean Vector** of all movies the user has liked, representing their specific taste.
5.  **Similarity Computation**: The engine performs a **Cosine Similarity** calculation between the User Vector and all candidate movie vectors to determine how closely they match.
6.  **Re-ranking**: Results are sorted by their similarity scores, ensuring the most relevant titles appear first in the UI.

### 💻 Stack Breakdown
- **Frontend**: `React 18`, `Vite`, `Tailwind CSS`, `Framer Motion`.
- **Backend**: `FastAPI` (Python), `SQLAlchemy` (PostgreSQL), `Pydantic`.
- **ML/AI**: `Scikit-Learn`, `Pandas`, `NumPy`.
- **Infrastructure**: `Vercel` (Frontend), `Render` (Backend), `TMDB API`.

## 🔄 Workflow

### 🛠️ Development Lifecycle
1.  **Feature Inception**: Define new cinematic features or UI enhancements.
2.  **Environment Setup**: Activate `.venv` (Backend) and `npm install` (Frontend).
3.  **Local Testing**: Run `uvicorn main:app` and `npm run dev` concurrently.
4.  **Schema Migrations**: Use SQLAlchemy models to update the PostgreSQL schema as needed.

### 🚀 Deployment Strategy
- **Frontend**: Automated CI/CD via **Vercel** (triggering on `main` branch push).
- **Backend**: Hosted on **Render** with a managed PostgreSQL instance.
- **Static Assets**: Movie posters and backdrops served directly from TMDB CDN.

## 🚀 Quick Start

### Live Link
Access the production deployment here: [**https://vaentv.vercel.app/**](https://vaentv.vercel.app/)

### Local Installation

#### 1. Backend (FastAPI)
```bash
cd backend
python -m venv .venv
# Activate venv: .\.venv\Scripts\activate (Windows) or source .venv/bin/activate (Unix)
pip install -r requirements.txt
# Configure .env with TMDB_API_KEY and DATABASE_URL
uvicorn main:app --reload
```

#### 2. Frontend (React + Vite)
```bash
cd frontend
npm install
npm run dev
```
